✅ PROCESO CORRECTO

1️⃣ COMPILAR FRONTEND A ESTÁTICOS
   cd C:\Proyectos\srtime-django\frontend
   npm run build
   
   Resultado:
   ├── static/index.html         ← React compilado
   ├── static/js/*.js            ← Bundles
   └── static/css/*.css          ← Estilos

2️⃣ INICIAR DJANGO (UN ÚNICO SERVIDOR)
   cd C:\Proyectos\srtime-django
   python manage.py runserver 127.0.0.1:9000
   
   Django sirve:
   ├── http://127.0.0.1:9000/               → index.html (React)
   ├── http://127.0.0.1:9000/api/v1/        → Endpoints
   └── http://127.0.0.1:9000/static/        → Assets

3️⃣ ACCEDER
   http://127.0.0.1:9000/employees
   
   ✅ FUNCIONA - Un puerto, un servidor
