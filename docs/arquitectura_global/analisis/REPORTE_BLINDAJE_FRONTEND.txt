3️⃣ CENTRALIZACIÓN DE LÓGICA DE COLORES DE STATUS
─────────────────────────────────────────────────
Archivo NUEVO: frontend/src/utils/statusColors.ts
Líneas: 1-28 (archivo completo)

CONTENIDO:
export const getStatusColor = (
    status: string,
    statusInfo?: { color?: string }
): string => {
    // Priority: backend-provided color
    if (statusInfo?.color) {
        return statusInfo.color;
    }

    // Fallback: CSS variable mapping
    const map: Record<string, string> = {
        "Normal": "var(--att-normal)",
        "Absent": "var(--att-absent)",
        "Late": "var(--att-late)",
        "Early": "var(--att-early)",
        "Partial": "var(--att-partial)",
        "Rest Day": "var(--att-rest-day)",
    };

    return map[status] || "var(--text-secondary)";
};

Archivo: frontend/src/pages/asistencia/Reports.tsx
Líneas: 8, 135-137

ANTES (lógica dispersa):
