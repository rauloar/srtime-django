# Alcance de la Versión Alfa

## Incluye

- Core de asistencia estable (cálculo operativo y timeline base).
- Separación explícita entre horario fijo y horario flexible.
- Horario flexible alineado al modelo ZKTime.Net 3.0 (no evaluativo).
- Data Entry aislado y sin persistencia directa al core.
- Endpoints básicos para operación diaria y visualización.

## Queda fuera

- FASE C (reglas defensivas y validaciones avanzadas).
- Inferencias automáticas de jornada o reglas de negocio adicionales.
- Ajustes manuales y flujos de revisión humana.
- Autenticación/seguridad completa (DEV mode vigente).
- Integraciones externas o reportería avanzada.
